# HITWH-major-selection
哈尔滨工业大学（威海）专业分流介绍手册

> 帮助哈尔滨工业大学（威海）的同学深入了解专业，打破信息差，做出适合自己的选择。

## 📖 关于本手册

面对大一春季学期的专业预分流，以及大二春季学期的专业正式分流，许多同学常常感到焦虑和迷茫。互联网上的信息虽然丰富，但良莠不齐，往往夹杂着过分偏激的看法，容易引起不必要的恐慌。

鉴于此，笔者编写了这份《HITWH 专业分流介绍手册》，旨在深入剖析各个专业的利与弊，帮助同学们总结信息，了解各个专业真实的样貌，为大家后续的专业分流提供客观的参考。

正如《序言》中所说：**“本科所学的专业无法完全限制你的发展，但是在当下这个竞争激烈的社会，你的专业决定了你将来大概率进入的行业。”** 因此，我们既不能过分看重，也不应过度轻视专业的选择。

## 🎯 面向对象

本手册主要面向 **2026 年哈尔滨工业大学（威海）物理类招生** 的以下集群（类）同学：
*   工科试验班（未来智造拔尖班）
*   工科试验班（未来信息）
*   工科试验班（未来智造卓越优才计划）
*   工科试验班（未来城市卓越优才计划）

**特别说明：**
*   针对 **工科试验班（未来城市卓越优才计划）** 的同学，手册中提供了转专业建议与留在本大类后的建议。
*   因理工交叉卓越优才计划（理学院）不存在分流选择，软件工程（卓越优才计划）不需要进行专业分流，故本手册不重点涉及。
